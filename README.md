Chess Board using HTML & CSS

A simple and clean chessboard created using HTML and CSS.
This project is perfect for beginners learning:

HTML table structure

CSS styling

Layout design

Working with alternating colors

Features

8×8 Chessboard layout

Alternating black and white squares

Clean and responsive design

Easy-to-understand code for beginners

Project Structure
project-folder/
│── index.html
└── style.css   (optional, if separated)

How to Run

Download or clone the project.

Open index.html in any web browser (Chrome, Firefox, Edge, etc.).

You will see the chessboard displayed.

How It Works (Short Explanation)

The chessboard is created using an HTML <table>

Each cell (<td>) is styled with CSS

CSS classes are used to alternate colors (black & white)

Code Highlights
HTML Structure

<table> → Creates the board

<tr> → Rows

<td> → Individual squares

CSS

width, height → Square size

nth-child() → Apply alternating colors

border → Board outline

Technologies Used

HTML5

CSS3
